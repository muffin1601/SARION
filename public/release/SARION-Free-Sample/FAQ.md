> Everything buyers ask, answered. Can't find yours? See [`SUPPORT.md`](SUPPORT.md).

## 📦 Product & Contents

**1. What exactly do I get?**
A 300+ page Markdown toolkit: 250+ prompts (plus 150 bonus), 60+ playbooks and workflows, 30+ templates, VS Code snippets, checklists, SOPs, and 3 worked examples. See [`VERSION.md`](VERSION.md) for the full breakdown.

**2. What format are the files in?**
Plain Markdown (`.md`) — universally readable and future-proof. Open them in VS Code, Obsidian, any Markdown viewer, or a browser. See [`INSTALL.md`](INSTALL.md).

**3. Can I export it to PDF?**
Yes. [`INSTALL.md`](INSTALL.md) covers three easy methods (VS Code extension, Obsidian, or browser print).

**4. Do I need to install anything to use it?**
No. It's pure Markdown — no dependencies, no build step. The optional VS Code snippets are a one-time paste.

---

## 🤖 Claude Code & Tech Stacks

**5. Which version of Claude Code does this work with?**
The kit is model- and version-agnostic. The prompts and playbooks are about *engineering technique*, not a specific build, so they stay useful across Claude Code updates.

**6. What tech stacks / languages are covered?**
The material is language-agnostic by design — the prompts and playbooks work across JavaScript/TypeScript, Python, Go, Java, and more. You supply the stack; the structure adapts.

**7. Do I need to be an expert to use this?**
No. [`START-HERE.md`](START-HERE.md) has a Beginner path. If you can copy and paste a prompt, you can use the kit.

**8. Will these prompts still work as Claude improves?**
Yes. They're built on durable principles (clear context, constraints, verification) rather than model quirks.
