# Start Here

> **This is your front door.** Whatever you're here to do, one of the three paths below gets you there fast. Pick the one that sounds like you.

You're now part of the **SARION ecosystem** — a growing family of premium, developer-first tools built on the same principle: opinionated, battle-tested, no filler. See [`SARION-Ecosystem.md`](SARION-Ecosystem.md) to see what else we build.

This page is the canonical starting point for the SARION Claude Code Mastery Kit — everything else branches from here.

---

## Choose Your Path

### Path 1 — New to Claude Code (Beginner)

Start slow, build fundamentals.

1. Read [`WELCOME.md`](WELCOME.md) — orient yourself.
2. Read [`Product-Overview.md`](Product-Overview.md) — see the whole map.
3. Follow [`Quick-Start-Guide.md`](Quick-Start-Guide.md) end to end.
4. Open `01-Prompts` and try 3 prompts on a small task.
5. Skim one worked example in `Examples/`.

> **Tip:** Don't try to absorb everything. Learn the *shape* of the kit; details come with use.

---

### Path 2 — Building Something Right Now

You have a task. Jump straight to the tool.

| If you need to… | Go to |
|:----------------|:------|
| Generate code or scaffold | `01-Prompts` |
| Fix a bug | `02-Debugging` + `02-Debugging-Workflows` |
| Design a system | `03-Architecture` + `03-Architecture-Playbook` |
| Clean up messy code | `04-Refactoring` + `04-Refactoring-Playbook` |
| Speed things up | `05-Performance-Playbook` |
| Write docs / README / PRD | `05-Documentation`, `06-PRDs`, `07-Readme-Templates` |
| Ship to production | `08-Deployment` + `10-Checklists` |
| Standardize a process | `09-SOPs` |

---

### Path 3 — Reference Material Only

Treat the kit as a lookup library.

- **Prompts:** `01-Prompts` (250+) and `12-Bonus` (150 more).
- **Cheat sheets:** `12-Bonus`.
- **Templates:** `05-Documentation`, `06-PRDs`, `07-Readme-Templates`.
- **Checklists:** `10-Checklists`.

> **Tip:** Use your editor's global search (`Ctrl/Cmd + Shift + F`) across the kit to find any keyword instantly.
